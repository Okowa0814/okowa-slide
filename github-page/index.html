基本概念

GitHub

存放與管理程式碼的平台。每個專案放在一個 Repository（簡稱 repo）裡。

GitHub Pages

GitHub 提供的免費網站服務，可以把 repo 裡的 HTML、CSS、JS 直接變成一個公開網址。

注意GitHub Pages 只能放靜態網頁，不能執行 PHP、資料庫等需要伺服器的程式。
準備

上傳前，先檢查你的檔案

01首頁叫 index.html

GitHub Pages 會自動打開這個檔案當作首頁。

02放在最外層

index.html 不要藏在其他資料夾裡。

03使用相對路徑

寫 images/me.jpg，不要寫 C:\Users\...

04注意大小寫

Photo.JPG 和 photo.jpg 在網路上是不同檔案。

05檔名用英文

避免中文與空格，可以用 - 連接，例如 about-me.html

一

註冊 GitHub 帳號

已經有帳號的同學，可以直接登入。

Step 1 · Sign up

註冊步驟

01前往 GitHub

打開 github.com，點右上角 Sign up

02填寫資料

輸入 Email、密碼、使用者名稱（Username）

03完成驗證

依畫面指示完成真人驗證

04收信確認

到信箱找 GitHub 寄來的驗證碼，輸入後完成註冊

想清楚再取名Username 會出現在你的網址裡，建議使用英文小寫，簡短好記。
二

建立 Repository

Repository 就像一個專屬資料夾，用來放這個網站的所有檔案。

Step 2 · New repository

建立 repo 步驟

01新增 repo

點右上角 + → New repository

02取名稱

在 Repository name 輸入英文名稱，例如 my-website

03設為 Public

免費帳號需要公開，才能使用 GitHub Pages

04建立

點 Create repository

網址怎麼來？

repo 名稱決定你的網址

repo 名稱
網站網址
my-website
https://username.github.io/my-website/
username.github.io
https://username.github.io/

把 username 換成自己的帳號名稱。如果 repo 取名為 username.github.io，網址會最短，適合當作個人主頁。

三

上傳網站檔案

不需要安裝任何軟體，直接在瀏覽器拖曳上傳。

Step 3 · Upload

上傳步驟

01

在 repo 頁面點 Add file → Upload files

02

把網站的檔案與資料夾拖進畫面

03

在下方簡短寫下這次做了什麼

04

點 Commit changes 完成上傳

上傳後的結構應該像這樣
my-website/ ├── index.html ← 首頁 ├── style.css ├── script.js └── images/ └── me.jpg
四

開啟 GitHub Pages

檔案上傳好後，只要設定一次，網站就會上線。

Step 4 · Deploy

部署設定

01打開設定

在 repo 上方點 Settings

02找到 Pages

左側選單點 Pages

03選擇來源

Source 選 Deploy from a branch

04選擇分支

Branch 選 main，資料夾選 / (root)

05儲存

點 Save，等待部署完成

完成部署

打開你的網站

等待

第一次部署通常需要一到數分鐘。

查看進度

點 repo 上方的 Actions，綠色勾勾代表完成。

取得網址

回到 Settings → Pages，點 Visit site。

之後想修改？

更新網站

01修改檔案

在自己的電腦上改好網站，或請 AI 協助修改

02重新上傳

Add file → Upload files，上傳同名檔案會直接覆蓋

03Commit

寫下這次改了什麼，點 Commit changes

04自動部署

GitHub 會自動重新部署，不需要再設定一次

看不到變化？等一兩分鐘，再按 Ctrl + F5（Mac 為 Cmd + Shift + R）強制重新整理。
五

常見問題

網站沒有正常顯示時，先對照下一頁檢查。

Troubleshooting

問題排查

狀況
可能的原因
出現 404 頁面
首頁不是 index.html、不在最外層，或還在部署中
圖片沒有顯示
路徑錯誤、檔名大小寫不符，或忘了上傳圖片資料夾
樣式全部消失
HTML 裡連結 CSS 的路徑錯誤
修改後沒有變化
部署尚未完成，或瀏覽器還在顯示舊版本
安全提醒

Public repo 裡的所有檔案，任何人都看得到。

不要上傳密碼、API 金鑰、身分證字號、住址或電話等個人資料。
